# Vue Enterprise Playbook

ArchitectOS Vue playbooks are organized into focused AI-friendly guides that make architecture, state management, API design, performance, and testing consumable for agents and engineers.

## Included Guides

- [Vue Enterprise Architecture](./architecture.md)
- [Vue Enterprise State Management](./state-management.md)
- [Vue Enterprise API Layer](./api-layer.md)
- [Vue Enterprise Performance](./performance.md)
- [Vue Enterprise Testing](./testing.md)

## How to Use

Each guide includes:

- preferred stack
- recommended architecture
- anti-patterns to avoid
- scaling advice
- production deployment recommendations
- code examples
- AI prompting examples

Use this folder as the canonical Vue playbook for ArchitectOS AI agents.

## Recommended File Structure

```
playbooks/vue/
  architecture.md
  state-management.md
  api-layer.md
  performance.md
  testing.md
```

## Why This Layout

- Each guide is narrowly scoped for AI consumption
- Topics are separated so agents can retrieve exactly what they need
- The structure maps directly to common engineering decisions
- It is easy to maintain and extend with new technology guidance
